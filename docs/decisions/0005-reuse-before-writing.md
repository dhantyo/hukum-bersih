# 0005 Reuse existing, tested code before writing our own

Date: 2026-11-20 · Decided by: Dante

Before building something, check whether it exists. Use the existing solution unless it is
clearly not elegant enough for us; record what was checked and why (docs/ARCHITECTURE.md,
"Reused instead of written"). Port pieces with credit when licences allow (AGPL-compatible).

Checked so far: Laws.Africa (Bluebell, law-widgets, Indigo), La Fabrique de la Loi, DuraLex,
Archéo Lex, LEOS, US bill tools, Pasal.id's parser, diff-match-patch.
