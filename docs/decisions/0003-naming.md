# 0003 Naming rule

Date: 2026-11-20 · Decided by: Dante, after comparing Fedlex (CH) and NeuRIS (DE)

Ids like `uu_11_2008`, versions `uu_11_2008_2008-04-21`, RUU documents
`ruu_<slug>_<date>_<type>`. Number before year, as Indonesians cite laws. No project name in
ids or titles; the project is mentioned only in archive.org descriptions. Full rule:
[NAMING.md](../NAMING.md).
