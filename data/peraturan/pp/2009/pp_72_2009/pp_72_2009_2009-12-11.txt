PREFACE
  PERATURAN PEMERINTAH REPUBLIK INDONESIA NOMOR 72 TAHUN 2009 TENTANG LALU LINTAS DAN ANGKUTAN KERETA API

PREAMBLE
  DENGAN RAHMAT TUHAN YANG MAHA ESA

  Menetapkan: bahwa untuk melaksanakan ketentuan Pasal 126, Pasal 129, Pasal 138, Pasal 146, Pasal 150, Pasal 156, Pasal 160, Pasal 163, Pasal 165, dan Pasal 171 Undang-Undang Nomor 23 Tahun 2007 tentang Perkeretaapian, perlu menetapkan Peraturan Pemerintah tentang Lalu Lintas dan Angkutan Kereta Api;

  BLOCKLIST
    ITEM 1.
      Pasal 5 ayat (2) Undang-Undang Dasar Negara Republik Indonesia Tahun 1945;

    ITEM 2.
      Undang-Undang Republik Indonesia Nomor 23 Tahun 2007 tentang Perkeretaapian (Lembaran Negara Republik Indonesia Tahun 2007 Nomor 65, Tambahan Lembaran Negara Republik Indonesia Nomor 4722); PERATURAN PEMERINTAH TENTANG LALU LINTAS DAN

  MEMUTUSKAN: ANGKUTAN KERETA API.

BODY
  CHAPTER I -

    ART 1 -
      Dalam Peraturan ini yang dimaksud dengan:

      POINT 1.
        Perkeretaapian adalah satu kesatuan sistem yang terdiri atas prasarana, sarana, dan sumber daya manusia, serta norma, kriteria, persyaratan, dan prosedur untuk penyelenggaraan transportasi kereta api.

      POINT 2.
        Kereta api adalah sarana perkeretaapian dengan tenaga gerak, baik berjalan sendiri maupun dirangkaikan dengan sarana perkeretaapian lainnya, yang akan ataupun sedang bergerak di jalan rel yang terkait dengan perjalanan kereta api.

      POINT 3.
        Jaringan pelayanan perkeretaapian adalah gabungan lintas-lintas pelayanan perkeretaapian.

      POINT 4.
        Lalu lintas kereta api adalah gerak sarana perkeretaapian di jalan rel.

      POINT 5.
        Angkutan kereta api adalah kegiatan pemindahan orang dan/atau barang dari satu tempat ke tempat lain dengan menggunakan kereta api.

      POINT 6.
        Awak sarana perkeretaapian adalah orang yang ditugaskan di dalam kereta api oleh penyelenggara sarana perkeretaapian selama perjalanan kereta api.

      POINT 7.
        Petugas pengatur perjalanan kereta api adalah orang yang melakukan pengaturan perjalanan kereta api dalam batas stasiun operasi atau beberapa stasiun operasi dalam wilayah pengaturannya.

      POINT 8.
        Petugas pengendali perjalanan kereta api adalah orang yang melakukan pengendalian perjalanan kereta api dari beberapa stasiun dalam wilayah pengendaliannya.

      POINT 9.
        Badan Usaha adalah Badan Usaha Milik Negara, Badan Usaha Milik Daerah, atau badan hukum Indonesia yang khusus didirikan untuk penyelenggaraan perkeretaapian.

      POINT 10.
        Penyelenggara sarana perkeretaapian adalah badan usaha yang mengusahakan sarana perkeretaapian umum.

      POINT 11.
        Penyelenggara prasarana perkeretaapian adalah pihak yang menyelenggarakan prasarana perkeretaapian.

      POINT 12.
        Jalur kereta api adalah jalur yang terdiri atas rangkaian petak jalan rel yang meliputi ruang manfaat jalur kereta api, ruang milik jalur kereta api, dan ruang pengawasan jalur kereta api, termasuk bagian atas dan bawahnya yang diperuntukkan bagi lalu lintas kereta api.

      POINT 13.
        Stasiun kereta api adalah tempat pemberangkatan dan pemberhentian kereta api.

      POINT 14.
        Stasiun operasi adalah stasiun kereta api yang memiliki fasilitas untuk bersilang, menyusul kereta api dan/atau langsir, dan dapat berfungsi untuk naik/turun penumpang dan/atau bongkar muat barang.

      POINT 15.
        Grafik Perjalanan Kereta Api yang selanjutnya disebut Gapeka adalah pedoman pengaturan pelaksanaan perjalanan kereta api yang digambarkan dalam bentuk garis yang menunjukkan stasiun, waktu, jarak, kecepatan, dan posisi perjalanan kereta api mulai dari berangkat, bersilang, bersusulan, dan berhenti yang digambarkan secara grafis untuk pengendalian perjalanan kereta api.

      POINT 16.
        Pemerintah Pusat yang selanjutnya disebut Pemerintah adalah Presiden Republik Indonesia yang memegang kekuasaan pemerintahan negara Republik Indonesia sebagaimana dimaksud dalam Undang-Undang Dasar 1945.

      POINT 17.
        Pengguna jasa adalah setiap orang dan/atau badan hukum yang menggunakan jasa angkutan kereta api, baik untuk angkutan orang maupun barang.

      POINT 18.
        Menteri adalah menteri yang menyelenggarakan urusan pemerintahan di bidang perkeretaapian.

  CHAPTER II -

    PART Kesatu - Umum

      ART 2 -
        PARA (1)
          Angkutan kereta api dilaksanakan pada jaringan jalur kereta api dalam lintas pelayanan kereta api yang membentuk jaringan pelayanan perkeretaapian. 2. sebagaimana

        PARA (2)
          Jaringan pelayanan perkeretaapian dimaksud pada ayat (1), terdiri atas: a. jaringan pelayanan perkeretaapian antarkota; dan b. jaringan pelayanan perkeretaapian perkotaan.

      ART 3 -
        PARA (1)
          Pelayanan angkutan kereta api merupakan layanan kereta api dalam satu lintas atau beberapa lintas pelayanan perkeretaapian yang dapat berupa bagian jaringan multimoda transportasi.

        PARA (2)
          Pelayanan angkutan kereta api sebagaimana dimaksud pada ayat (1) dapat bersifat komersial atau bersifat penugasan sesuai dengan kebutuhan masyarakat

      ART 4 -
        Lintas pelayanan sebagaimana dimaksud dalam Pasal 3 ayat (1) ditetapkan dengan memperhatikan:

        POINT a.
          jenis pelayanan yang dibutuhkan masyarakat;

        POINT b.
          kapasitas lintas yang dibutuhkan masyarakat;

        POINT c.
          kebutuhan jasa angkutan pada lintas pelayanan;

        POINT d.
          komposisi jenis pelayanan angkutan kereta api sesuai dengan tingkat pelayanan;

        POINT e.
          keterpaduan intra dan antarmoda transportasi;

        POINT f.
          jarak waktu antarkereta api (headway), jarak antara stasiun dan perhentian;

        POINT g.
          jarak pusat kegiatan dan pusat logistik terhadap terminal/stasiun; dan

        POINT h.
          ketersediaan waktu untuk perpindahan intra dan antarmoda.

      ART 5 -
        Jaringan pelayanan perkeretaapian merupakan kumpulan lintas pelayanan yang tersambung satu dengan yang lain menghubungkan lintas pelayanan perkeretaapian dengan pusat kegiatan, pusat logistik, dan antarmoda.

    PART Kedua - Jaringan Pelayanan Perkeretaapian Antarkota

      ART 6 -
        Jaringan pelayanan perkeretaapian antarkota sebagaimana dimaksud dalam Pasal 2 ayat (2) huruf a merupakan pelayanan yang menghubungkan:

        POINT a.
          antarkota antarnegara;

        POINT b.
          antarkota antarprovinsi;

        POINT c.
          antarkota dalam provinsi; dan

        POINT d.
          antarkota dalam kabupaten/kota.

      ART 7 -
        PARA (1)
          Jaringan pelayanan perkeretaapian antarkota antarnegara sebagaimana dimaksud dalam Pasal 6 huruf a ditetapkan oleh Menteri berdasarkan perjanjian antarnegara.

        PARA (2)
          Jaringan pelayanan perkeretaapian antarkota antarprovinsi sebagaimana dimaksud dalam Pasal 6 huruf b dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api nasional ditetapkan oleh Menteri.

        PARA (3)
          Jaringan pelayanan perkeretaapian antarkota dalam provinsi sebagaimana dimaksud dalam Pasal 6 huruf c dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api provinsi ditetapkan oleh gubernur.

        PARA (4)
          Jaringan pelayanan perkeretaapian antarkota dalam kabupaten/kota sebagaimana dimaksud dalam Pasal 6 huruf d dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api kabupaten/kota ditetapkan oleh bupati/walikota.

      ART 8 -
        PARA (1)
          Jaringan pelayanan perkeretaapian antarkota dalam provinsi sebagaimana dimaksud dalam Pasal 7 ayat (3), jaringan pelayanan perkeretaapian antarkota dalam kabupaten/kota sebagaimana dimaksud dalam Pasal 7 ayat (4), dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api nasional ditetapkan oleh Menteri.

        PARA (2)
          Jaringan pelayanan perkeretaapian antarkota dalam kabupaten/kota sebagaimana dimaksud dalam Pasal 7 ayat (4) dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api provinsi ditetapkan oleh gubernur.

      ART 9 -
        Jaringan pelayanan perkeretaapian antarkota diselenggarakan dengan ciri-ciri pelayanan:

        POINT a.
          menghubungkan beberapa stasiun antarkota;

        POINT b.
          tidak menyediakan layanan penumpang berdiri;

        POINT c.
          melayani penumpang tidak tetap;

        POINT d.
          memiliki jarak dan/atau waktu tempuh panjang;

        POINT e.
          memiliki frekuensi kereta api sedang atau rendah; dan

        POINT f.
          melayani kebutuhan angkutan penumpang dan/atau barang antarkota.

    PART Ketiga - Jaringan Pelayanan Perkeretaapian Perkotaan

      ART 10 -
        Jaringan pelayanan perkeretaapian perkotaan sebagaimana dimaksud dalam Pasal 2 ayat (2) huruf b yang berada dalam suatu wilayah perkotaan dapat:

        POINT a.
          melampaui 1 (satu) provinsi;

        POINT b.
          melampaui 1 (satu) kabupaten/kota dalam 1 (satu) provinsi; dan

        POINT c.
          berada dalam 1 (satu) kabupaten/kota.

      ART 11 -
        PARA (1)
          Jaringan pelayanan perkeretaapian perkotaan yang melampaui 1 (satu) provinsi sebagaimana dimaksud dalam Pasal 10 huruf a dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api nasional ditetapkan oleh Menteri.

        PARA (2)
          Jaringan pelayanan perkeretaapian perkotaan yang melampaui 1 (satu) kabupaten/kota dalam 1 (satu) provinsi sebagaimana dimaksud dalam Pasal 10 huruf b dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api provinsi ditetapkan oleh gubernur.

        PARA (3)
          Jaringan pelayanan perkeretaapian perkotaan yang berada dalam 1 (satu) kabupaten/kota sebagaimana dimaksud dalam Pasal 10 huruf c dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api kabupaten/kota ditetapkan oleh bupati/walikota.

      ART 12 -
        PARA (1)
          Jaringan pelayanan perkeretaapian perkotaan yang melampaui 1 (satu) kabupaten/kota dalam 1 (satu) provinsi dan yang berada dalam 1 (satu) kabupaten/kota sebagaimana dimaksud dalam Pasal 11 ayat (2) dan ayat (3) dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api nasional ditetapkan oleh Menteri.

        PARA (2)
          Jaringan pelayanan perkeretaapian perkotaan yang berada dalam 1 (satu) kabupaten/kota sebagaimana dimaksud dalam Pasal 11 ayat (3) dan lintas pelayanan kereta api yang berada pada jaringan jalur kereta api provinsi ditetapkan oleh gubernur.

      ART 13 -
        PARA (1)
          Menteri, gubernur, atau bupati/walikota sesuai kewenangannya menetapkan lintas pelayanan atas permohonan penyelenggara sarana perkeretaapian.

        PARA (2)
          Menteri, gubernur, atau bupati/walikota sesuai kewenangannya dapat menolak permohonan penetapan lintas pelayanan dalam hal lintas pelayanan tidak sesuai dengan ketentuan sebagaimana dimaksud dalam Pasal 4.

      ART 14 -
        Dalam hal adanya kebutuhan angkutan pada suatu lintas pelayanan tertentu dan tidak terdapat permohonan dari penyelenggara sarana perkeretaapian sebagaimana dimaksud dalam Pasal 13 ayat (1), Menteri, gubernur, atau bupati/walikota dapat menetapkan lintas pelayanan.

      ART 15 -
        Jaringan pelayanan perkeretaapian perkotaan diselenggarakan dengan ciri-ciri pelayanan:

        POINT a.
          menghubungkan beberapa stasiun di wilayah perkotaan;

        POINT b.
          melayani banyak penumpang berdiri;

        POINT c.
          memiliki sifat perjalanan ulang alik/komuter;

        POINT d.
          melayani penumpang tetap;

        POINT e.
          memiliki jarak dan/atau waktu tempuh pendek; dan

        POINT f.
          melayani kebutuhan angkutan penumpang di dalam kota dan dari daerah sub-urban menuju pusat kota atau sebaliknya.

      ART 16 -
        Ketentuan lebih lanjut mengenai tata cara penetapan jaringan pelayanan dan lintas pelayanan perkeretaapian antarkota dan perkotaan diatur dengan peraturan Menteri.

  CHAPTER III -

    PART Kesatu - Prinsip Lalu Lintas Kereta Api

      ART 17 -
        PARA (1)
          Jalur kereta api untuk kepentingan perjalanan kereta api dibagi dalam beberapa petak blok.

        PARA (2)
          Petak blok dibatasi oleh dua sinyal berurutan sesuai dengan arah perjalanan yang terdiri atas:

          POINT a.
            sinyal masuk dan sinyal keluar pada 1 (satu) stasiun;

          POINT b.
            sinyal keluar dan sinyal blok;

          POINT c.
            sinyal keluar dan sinyal masuk di stasiun berikutnya;

          POINT d.
            sinyal blok dan sinyal blok berikutnya; atau

          POINT e.
            sinyal blok dan sinyal masuk.

        PARA (3)
          Dalam 1 (satu) petak blok pada jalur kereta api hanya diizinkan dilewati oleh 1 (satu) kereta api.

        PARA (4)
          Dalam keadaan tertentu pada 1 (satu) petak blok pada jalur kereta api dapat dilewati lebih dari 1 (satu) kereta api berdasarkan izin yang diberikan oleh petugas pengatur perjalanan kereta api.

        PARA (5)
          Perjalanan kereta api yang memasuki petak blok yang di dalamnya terdapat kereta api atau sarana perkeretaapian dilakukan dengan kecepatan terbatas dan pengamanan khusus.

      ART 18 -
        PARA (1)
          Pengoperasian kereta api pada jalur ganda atau lebih harus menggunakan jalur kanan.

        PARA (2)
          Dalam keadaan tertentu, pengoperasian kereta api pada jalur ganda atau lebih dapat menggunakan jalur kiri.

        PARA (3)
          Penggunaan jalur kiri sebagaimana dimaksud pada ayat (2) dilaksanakan dengan ketentuan:

          POINT a.
            setelah mendapat perintah dari petugas pengatur perjalanan kereta api; atau

          POINT b.
            terdapat sinyal jalur kiri (sinyal berjalan jalur tunggal sementara) yang mengizinkan kereta api untuk berjalan pada jalur kiri dengan kecepatan terbatas.

      ART 19 -
        PARA (1)
          Kereta api yang berjalan langsung di stasiun dilewatkan pada jalur kereta api lurus, kecuali di stasiun persimpangan untuk ke jalur tertentu, di peralihan jalur kereta api dari jalur ganda ke jalur tunggal dan sebaliknya, atau stasiun yang tidak memiliki jalur lurus sesuai dengan peraturan pengamanan setempat.

        PARA (2)
          Dalam hal jalur kereta api lurus sebagaimana dimaksud pada ayat (1) tidak dapat dilewati karena adanya gangguan operasi, kereta api yang berjalan langsung dilewatkan melalui jalur kereta api belok dengan kecepatan terbatas dan pengamanan khusus.

      ART 20 -
        Ketentuan lebih lanjut mengenai prinsip lalu lintas kereta api diatur dengan peraturan Menteri.

    PART Kedua - Kecepatan dan Frekuensi Kereta Api

      ART 21 -
        Kecepatan maksimum kereta api ditentukan berdasarkan:

        POINT a.
          kecepatan maksimum yang paling rendah antara kecepatan maksimum kemampuan jalur dan kecepatan maksimum sarana perkeretaapian; dan

        POINT b.
          sifat barang yang diangkut.

      ART 22 -
        PARA (1)
          Untuk kepentingan pengoperasian kereta api dan menjamin keselamatan perjalanan kereta api, pada setiap lintas pelayanan ditentukan frekuensi kereta api yang didasarkan pada:

          POINT a.
            kemampuan jalur kereta api yang dapat dilewati kereta api sesuai dengan kecepatan sarana perkeretaapian;

          POINT b.
            jarak antara dua stasiun atau petak blok; dan

          POINT c.
            fasilitas operasi.

        PARA (2)
          Frekuensi perjalanan kereta api dapat digolongkan dalam:

          POINT a.
            frekuensi rendah;

          POINT b.
            frekuensi sedang; dan

          POINT c.
            frekuensi tinggi.

      ART 23 -
        Ketentuan lebih lanjut mengenai kecepatan dan frekuensi kereta api diatur dengan peraturan Menteri.

    PART Ketiga - Gapeka

      ART 24 -
        PARA (1)
          Pelaksanaan perjalanan kereta api yang dimulai dari stasiun keberangkatan, bersilang, bersusulan, dan berhenti di stasiun tujuan diatur berdasarkan Gapeka.

        PARA (2)
          Gapeka sebagaimana dimaksud pada ayat (1) dibuat oleh pemilik prasarana perkeretaapian didasarkan pada pelayanan angkutan kereta api yang akan dilaksanakan.

        PARA (3)
          Pembuatan Gapeka oleh pemilik prasarana perkeretaapian sebagaimana dimaksud pada ayat (2), harus memperhatikan:

          POINT a.
            masukan dari penyelenggara sarana perkeretaapian;

          POINT b.
            kebutuhan angkutan kereta api; dan

          POINT c.
            sarana perkeretaapian yang ada.

        PARA (4)
          Gapeka dapat berupa:

          POINT a.
            Gapeka pada jaringan jalur kereta api nasional;

          POINT b.
            Gapeka pada jaringan jalur kereta api provinsi; dan

          POINT c.
            Gapeka pada jaringan jalur kereta api kabupaten/ kota.

      ART 25 -
        Gapeka dapat diubah apabila terdapat perubahan pada:

        POINT a.
          kebutuhan angkutan;

        POINT b.
          jumlah sarana perkeretaapian;

        POINT c.
          kecepatan kereta api;

        POINT d.
          prasarana perkeretaapian; dan/atau

        POINT e.
          keadaan memaksa.

      ART 26 -
        PARA (1)
          Penyelenggara sarana perkeretaapian harus mengumumkan jadwal perjalanan kereta api yang termuat dalam Gapeka kepada masyarakat.

        PARA (2)
          Pengumuman sebagaimana dimaksud pada ayat (1) dilaksanakan melalui media massa dan ditempel di stasiun, sebelum pemberlakuan Gapeka.

      ART 27 -
        PARA (1)
          Penyelenggara prasarana perkeretaapian melaporkan pelaksanaan Gapeka secara berkala setiap 3 (tiga) bulan kepada Menteri, gubernur, atau bupati/walikota sesuai dengan kewenangannya.

        PARA (2)
          Menteri, gubernur, atau bupati/walikota sesuai kewenangannya, melakukan pengawasan terhadap pelaksanaan Gapeka.

        PARA (3)
          Dalam hal terdapat pelanggaran dalam pelaksanaan Gapeka, penyelenggara prasarana perkeretaapian dikenai sanksi administratif berupa peringatan, pembekuan izin operasi, dan/atau pencabutan izin.

      ART 28 -
        PARA (1)
          Perjalanan kereta api luar biasa dapat dilaksanakan oleh penyelenggara prasarana perkeretaapian atau penyelenggara sarana perkeretaapian.

        PARA (2)
          Dalam hal perjalanan kereta api luar biasa sebagaimana dimaksud pada ayat (1) dilaksanakan oleh penyelenggara sarana perkeretaapian, harus mendapat persetujuan dari penyelenggara prasarana perkeretaapian.

      ART 29 -
        Ketentuan lebih lanjut mengenai tata cara dan standar pembuatan Gapeka diatur dengan peraturan Menteri.

    PART Keempat - Pengaturan Perjalanan Kereta Api

      ART 30 -
        PARA (1)
          Pengaturan perjalanan kereta api terdiri atas wilayah pengaturan:

          POINT a.
            setempat;

          POINT b.
            daerah; dan

          POINT c.
            terpusat.

        PARA (2)
          Pengaturan perjalanan kereta api sebagaimana dimaksud pada ayat (1) dilakukan oleh petugas pengatur perjalanan kereta api sesuai Gapeka.

        PARA (3)
          Petugas pengatur perjalanan kereta api sebagaimana dimaksud pada ayat (2) bertanggung jawab terhadap keselamatan urusan perjalanan kereta api di wilayah pengaturannya.

      ART 31 -
        Pengaturan perjalanan kereta api setempat sebagaimana dimaksud dalam Pasal 30 ayat (1) huruf a dilaksanakan oleh petugas pengatur perjalanan kereta api di stasiun yang bersangkutan.

      ART 32 -
        Pengaturan perjalanan kereta api daerah sebagaimana dimaksud dalam Pasal 30 ayat (1) huruf b dilaksanakan oleh petugas pengatur perjalanan kereta api di stasiun yang ditetapkan oleh penyelenggara prasarana perkeretaapian untuk pengaturan perjalanan kereta api pada 2 (dua) stasiun atau lebih.

      ART 33 -
        Pengaturan perjalanan kereta api terpusat sebagaimana dimaksud dalam Pasal 30 ayat (1) huruf c dilaksanakan oleh petugas pengatur perjalanan kereta api di suatu tempat tertentu untuk pengaturan perjalanan kereta api dalam 1 (satu) wilayah pengaturan.

      ART 34 -
        PARA (1)
          Dalam hal perjalanan kereta api tidak sesuai Gapeka sebagaimana dimaksud dalam Pasal 30 ayat (2), pengaturan perjalanan kereta api dilakukan oleh petugas pengendali perjalanan kereta api dan pelaksanaannya oleh petugas pengatur perjalanan kereta api.

        PARA (2)
          Pengaturan oleh petugas pengendali perjalanan kereta api sebagaimana dimaksud pada ayat (1) dilakukan melalui alat komunikasi yang direkam.

        PARA (3)
          Pengaturan perjalanan kereta api yang dilakukan oleh petugas pengendali perjalanan kereta api sebagaimana dimaksud pada ayat (1), tidak mengurangi tanggung jawab petugas pengatur perjalanan kereta api.

      ART 35 -
        Pengaturan perjalanan kereta api dilakukan dengan semboyan berupa:

        POINT a.
          isyarat dari petugas pengatur perjalanan kereta api;

        POINT b.
          sinyal;

        POINT c.
          tanda; atau

        POINT d.
          marka.

      ART 36 -
        PARA (1)
          Sinyal sebagaimana dimaksud dalam Pasal 35 huruf b terdiri atas:

          POINT a.
            sinyal utama;

          POINT b.
            sinyal pembantu; dan

          POINT c.
            sinyal pelengkap.

        PARA (2)
          Sinyal utama sebagaimana dimaksud pada ayat (1) huruf a meliputi:

          POINT a.
            sinyal masuk;

          POINT b.
            sinyal keluar;

          POINT c.
            sinyal blok;

          POINT d.
            sinyal darurat; dan

          POINT e.
            sinyal langsir.

        PARA (3)
          Sinyal pembantu sebagaimana dimaksud pada ayat (1) huruf b meliputi:

          POINT a.
            sinyal muka;

          POINT b.
            sinyal pendahulu; dan

          POINT c.
            sinyal pengulang.

        PARA (4)
          Sinyal pelengkap sebagaimana dimaksud pada ayat (1) huruf c meliputi:

          POINT a.
            sinyal penunjuk arah;

          POINT b.
            sinyal pembatas kecepatan; dan

          POINT c.
            sinyal berjalan jalur tunggal sementara.

      ART 37 -
        Tanda sebagaimana dimaksud dalam Pasal 35 huruf c berfungsi untuk memberi peringatan atau petunjuk yang harus dipatuhi oleh masinis.

      ART 38 -
        Marka sebagaimana dimaksud dalam Pasal 35 huruf d berfungsi sebagai peringatan, petunjuk, batas, atau pembeda kepada masinis mengenai kondisi tertentu pada suatu tempat tertentu yang terkait dengan perjalanan kereta api.

      ART 39 -
        Ketentuan lebih lanjut mengenai pengaturan perjalanan kereta api diatur dengan peraturan Menteri.

    PART Kelima - Persiapan Perjalanan Kereta Api

      Umum

      ART 40 -
        PARA (1)
          Penyelenggara sarana perkeretaapian harus mempersiapkan perjalanan kereta api.

        PARA (2)
          Persiapan perjalanan kereta api sebagaimana dimaksud pada ayat (1) meliputi kegiatan:

          POINT a.
            menyiapkan sarana dengan atau tanpa rangkaiannya;

          POINT b.
            menyiapkan awak sarana perkeretaapian;

          POINT c.
            memeriksa sarana perkeretaapian;

          POINT d.
            menyediakan waktu kereta api sesuai dengan jalur yang terjadwal di stasiun awal;

          POINT e.
            memasang tanda; dan

          POINT f.
            menyiapkan dokumen perjalanan kereta api.

      ART 41 -
        Penyiapan sarana dengan atau tanpa rangkaiannya sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf a, meliputi kegiatan:

        POINT a.
          menyiapkan lokomotif, kereta atau gerbong, kereta dengan penggerak sendiri, atau peralatan khusus, untuk didinaskan dalam perjalanan kereta api; dan

        POINT b.
          menentukan susunan rangkaian sarana perkeretaapian untuk dirangkai oleh penyelenggara prasarana perkeretaapian menjadi rangkaian kereta api yang akan berangkat sesuai dengan persyaratan teknis operasi untuk keselamatan perjalanan kereta api.

      ART 42 -
        Penyiapan awak sarana perkeretaapian sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf b, paling sedikit meliputi kegiatan:

        POINT a.
          memeriksa sertifikat kecakapan;

        POINT b.
          memeriksa kesehatan; dan

        POINT c.
          memberi surat tugas.

      ART 43 -
        PARA (1)
          Pemeriksaan sarana perkeretaapian sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf c, paling sedikit meliputi pemeriksaan terhadap:

          POINT a.
            perangkat pengereman;

          POINT b.
            peralatan keselamatan;

          POINT c.
            peralatan perangkai; dan

          POINT d.
            kelistrikan.

        PARA (2)
          Pemeriksaan sarana perkeretaapian sebagaimana dimaksud pada ayat (1), baik untuk kereta api antarkota maupun perkotaan, dilakukan pada saat awal pengoperasian di stasiun awal.

      ART 44 -
        Penyediaan waktu kereta api sesuai dengan jalur yang terjadwal di stasiun awal sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf d, dilaksanakan untuk pelayanan kepada pengguna jasa kereta api dengan kegiatan:

        POINT a.
          memeriksa dokumen perjalanan kereta api;

        POINT b.
          mencocokkan jam yang digunakan masinis dan kondektur dengan jam induk di stasiun;

        POINT c.
          mengawasi naiknya penumpang; dan

        POINT d.
          memuat barang bawaan dan barang kiriman di kereta bagasi.

      ART 45 -
        Pemasangan tanda sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf e dilakukan pada:

        POINT a.
          ujung belakang kereta api; dan

        POINT b.
          tempat lain di kereta api sesuai dengan kebutuhan.

      ART 46 -
        Penyiapan dokumen perjalanan kereta api sebagaimana dimaksud dalam Pasal 40 ayat (2) huruf f, meliputi:

        POINT a.
          keterangan kelaikan sarana perkeretaapian;

        POINT b.
          keterangan tentang rangkaian kereta api, jadwal perjalanan, termasuk tempat bersilang atau penyusulan kereta api;

        POINT c.
          dokumen untuk mencatat kejadian selama perjalanan kereta api; dan

        POINT d.
          dokumen yang diperlukan untuk masinis.

      ART 47 -
        Ketentuan lebih lanjut mengenai tata cara mempersiapkan perjalanan kereta api diatur dengan peraturan Menteri.

      SUBPART 2 - Penempatan Lokomotif dalam Rangkaian

        ART 48 -
          PARA (1)
            Untuk menjamin keselamatan dan dengan memperhatikan daya tarik rangkaian, lokomotif ditempatkan pada bagian depan rangkaian kereta api.

          PARA (2)
            Pada tanjakan dengan gradien tertentu dan/atau kondisi yang mengharuskan, lokomotif dapat ditempatkan di bagian belakang rangkaian sebagai lokomotif pendorong.

        ART 49 -
          PARA (1)
            Rangkaian kereta api dapat menggunakan 2 (dua) lokomotif atau lebih.

          PARA (2)
            Rangkaian kereta api dengan 2 (dua) lokomotif atau lebih, lokomotif kedua atau selebihnya dengan pertimbangan teknis dapat ditempatkan di tengah atau di belakang rangkaian kereta api.

          PARA (3)
            Dalam hal pada 1 (satu) rangkaian kereta api memerlukan 2 (dua) lokomotif atau lebih, masinis yang berada pada lokomotif paling depan mengendalikan jalannya kereta api.

        ART 50 -
          Ketentuan lebih lanjut mengenai tata cara penempatan lokomotif dalam rangkaian kereta api diatur dengan peraturan Menteri.

      SUBPART 3 - Pemeriksaan Jalur

        ART 51 -
          PARA (1)
            Untuk keselamatan perjalanan kereta api, jalur kereta api harus diadakan pemeriksaan secara berkala, paling sedikit 2 (dua) kali dalam waktu 24 (dua puluh empat) jam.

          PARA (2)
            Pemeriksaan jalur dilakukan oleh petugas pemeriksa jalur dengan membawa peralatan yang diperlukan.

          PARA (3)
            Petugas pemeriksa jalur harus melaporkan kondisi jalur kereta api di wilayah tugasnya kepada petugas pengatur perjalanan kereta api di stasiun akhir tugasnya.

          PARA (4)
            Pelaksanaan dan waktu pemeriksaan jalur diatur oleh penyelenggara prasarana perkeretaapian.

        ART 52 -
          Ketentuan lebih lanjut mengenai tata cara pemeriksaan jalur kereta api diatur dengan peraturan Menteri.

    PART Keenam - Hubungan Blok

      ART 53 -
        PARA (1)
          Hubungan blok dalam petak blok antara 2 (dua) stasiun untuk perjalanan kereta api terdiri atas:

          POINT a.
            hubungan manual; dan

          POINT b.
            hubungan otomatis.

        PARA (2)
          Hubungan manual sebagaimana dimaksud pada ayat (1) huruf a meliputi:

          POINT a.
            telegraf;

          POINT b.
            blok elektromekanis; dan

          POINT c.
            blok elektris.

        PARA (3)
          Hubungan otomatis sebagaimana dimaksud pada ayat (1) huruf b meliputi:

          POINT a.
            otomatis tertutup; dan

          POINT b.
            otomatis terbuka.

      ART 54 -
        PARA (1)
          Hubungan telegraf sebagaimana dimaksud dalam Pasal 53 ayat (2) huruf a dilakukan dalam memberi warta kereta api.

        PARA (2)
          Hubungan blok elektromekanis dan blok elektris sebagaimana dimaksud dalam Pasal 53 ayat (2) huruf b dan huruf c dilakukan dengan mengoperasikan peralatan sesuai dengan peraturan pengamanan setempat.

      ART 55 -
        PARA (1)
          Pertukaran warta kereta api harus dilaksanakan antara petugas pengatur perjalanan kereta api di stasiun terdekat yang bersebelahan yang memiliki faslitas untuk warta kereta api.

        PARA (2)
          Warta kereta api harus terekam/tercatat untuk keperluan pembuktian.

      ART 56 -
        Apabila terdapat gangguan hubungan blok, hubungan dilakukan dengan hubungan blok darurat setelah petugas pengatur perjalanan kereta api menjamin:

        POINT a.
          wesel dalam kondisi aman;

        POINT b.
          petak blok dalam kondisi aman; dan

        POINT c.
          dari arah berlawanan tidak akan atau sedang menjalankan kereta api.

      ART 57 -
        Ketentuan lebih lanjut mengenai tata cara hubungan blok diatur dengan peraturan Menteri.

    PART Ketujuh - Pemberangkatan Kereta Api

      ART 58 -
        Penyiapan dan pelaksanaan pemberangkatan kereta api dilakukan melalui tahapan:

        POINT a.
          penyiapan pegawai stasiun;

        POINT b.
          penyiapan rute kereta api berangkat;

        POINT c.
          penyiapan kereta api berangkat;

        POINT d.
          pemberian perintah berangkat;

        POINT e.
          pengawasan pemberangkatan kereta api;

        POINT f.
          mengembalikan kedudukan persinyalan pada posisi awal; dan

        POINT g.
          pemberian warta berangkat kepada stasiun berikutnya.

      ART 59 -
        Penyiapan pegawai stasiun sebagaimana dimaksud dalam Pasal 58 huruf a dilakukan untuk pengoperasian kereta api.

      ART 60 -
        Penyiapan rute kereta api berangkat sebagaimana dimaksud dalam Pasal 58 huruf b merupakan kegiatan mengatur kedudukan wesel dan sinyal yang menunjukkan indikasi aman untuk dilalui kereta api yang akan berangkat.

      ART 61 -
        Penyiapan kereta api berangkat sebagaimana dimaksud dalam Pasal 58 huruf c meliputi:

        POINT a.
          masinis sudah berada di kabin masinis;

        POINT b.
          kondektur di samping kereta api;

        POINT c.
          penumpang dan/atau barang berada di kereta atau gerbong; dan

        POINT d.
          pengatur perjalanan kereta api berada di tempatnya.

      ART 62 -
        Pemberian perintah berangkat sebagaimana dimaksud dalam Pasal 58 huruf d dilakukan oleh petugas pengatur perjalanan kereta api melalui sinyal dan tanda indikasi aman.

      ART 63 -
        PARA (1)
          Pengawasan pemberangkatan kereta api sebagaimana dimaksud dalam Pasal 58 huruf e dilakukan oleh petugas pengatur perjalanan kereta api atau didelegasikan kepada petugas lain yang ditugaskan untuk itu.

        PARA (2)
          Pengawasan sebagaimana dimaksud pada ayat (1) dilakukan sampai kereta api melewati wesel terjauh.

      ART 64 -
        Mengembalikan kedudukan persinyalan pada posisi awal sebagaimana dimaksud dalam Pasal 58 huruf f, dilakukan setelah kereta api melewati wesel terjauh di stasiun.

      ART 65 -
        PARA (1)
          Pemberian warta berangkat kepada stasiun berikutnya sebagaimana dimaksud dalam pasal 58 huruf g, dilakukan dalam waktu secepatnya setelah kereta api berangkat oleh petugas pengatur perjalanan kereta api dengan memberi warta berangkat kepada petugas pengatur perjalanan kereta api stasiun terdekat berikutnya yang memiliki fasilitas warta kereta api.

        PARA (2)
          Pemberian warta berangkat sebagaimana dimaksud pada ayat (1) berlaku untuk hubungan blok manual.

      ART 66 -
        PARA (1)
          Pada saat kereta api akan melewati wesel terjauh di stasiun, masinis harus memperhatikan tanda akhir belakang rangkaian kereta api untuk memastikan tidak terdapat bagian belakang rangkaian kereta api tertinggal atau terlepas.

        PARA (2)
          Dalam hal terdapat rangkaian kereta api yang tertinggal atau terlepas sebagaimana dimaksud pada ayat (1), masinis harus menghentikan kereta api.

        PARA (3)
          Apabila di stasiun dilengkapi dengan sinyal mekanis atau elektromekanis untuk jalur tunggal, masinis harus memperhatikan sinyal masuk untuk kereta api yang berlawanan arah.

        PARA (4)
          Dalam hal sinyal masuk untuk kereta api yang berlawanan arah sebagaimana dimaksud pada ayat (3) menunjukkan indikasi jalur tidak aman, masinis harus memberhentikan kereta api dan menunggu perintah petugas pengatur perjalanan kereta api.

      ART 67 -
        Dalam hal tidak memungkinkan masinis memastikan bagian belakang rangkaian kereta api tidak terlihat sebagaimana dimaksud pada Pasal 66 ayat (1), maka masinis dibebaskan atas tanggung jawab memperhatikan tanda ujung belakang rangkaian kereta api.

      ART 68 -
        Ketentuan lebih lanjut mengenai tata cara pemberangkatan kereta api diatur dengan peraturan Menteri

    PART Kedelapan - Kereta Api dalam Perjalanan

      ART 69 -
        Perjalanan kereta api pada petak blok merupakan perjalanan kereta api dari:

        POINT a.
          sinyal keluar sampai sinyal blok;

        POINT b.
          sinyal blok sampai sinyal blok berikutnya;

        POINT c.
          sinyal blok sampai sinyal masuk; atau

        POINT d.
          sinyal keluar pada suatu stasiun sampai sinyal masuk di stasiun berikutnya.

      ART 70 -
        PARA (1)
          Perjalanan kereta api sebagaimana dimaksud dalam Pasal 69 pada jalur yang menggunakan sinyal blok, dalam hal sinyal blok mengindikasikan tidak aman, masinis harus mengikuti peraturan yang berlaku.

        PARA (2)
          Ketentuan lebih lanjut mengenai tata cara memasuki sinyal blok tidak aman sebagaimana dimaksud pada ayat (1) diatur dengan peraturan Menteri.

      ART 71 -
        PARA (1)
          Pada jalur kereta api menurun dengan gradien/derajat tertentu, kereta api yang akan menurun harus berhenti di stasiun terdekat sebelum turunan untuk dilakukan pemeriksaan sistem pengereman dan fasilitas lainnya.

        PARA (2)
          Gradien/derajat tertentu sebagaimana dimaksud pada ayat (1) ditetapkan oleh Menteri dengan memperhatikan keselamatan perjalanan kereta api.

        PARA (3)
          Stasiun sebagaimana dimaksud pada ayat (1) harus ditetapkan dalam Gapeka.

      ART 72 -
        PARA (1)
          Masinis yang bertugas dalam perjalanan kereta api harus melaporkan kepada petugas pengendali perjalanan kereta api pada stasiun keberangkatan dan pada saat perpindahan wilayah pengendalian melalui peralatan telekomunikasi yang direkam.

        PARA (2)
          Dalam hal masinis menemukan kejanggalan pada jalur yang telah dilewati, masinis harus segera melaporkan kepada petugas pengendali perjalanan kereta api mengenai kejanggalan jalur tersebut disertai laporan mengenai kondisi jalur kereta api, sinyal, perlintasan, dan kondisi catu daya yang telah dilewati, melalui peralatan telekomunikasi.

      ART 73 -
        PARA (1)
          Pada jalur kereta api bergigi, lebih dari 1 (satu) rangkaian kereta api dapat berjalan beriringan dalam 1 (satu) kelompok dalam satu petak blok.

        PARA (2)
          Perjalanan kereta api dalam kelompok sebagaimana dimaksud pada ayat (1) harus memperhatikan jarak dan tenggat waktu yang aman antarkereta api.

        PARA (3)
          Apabila salah satu kereta api dalam kelompok terlambat, petugas pengatur perjalanan kereta api harus memberitahukan kepada petugas pengatur perjalanan kereta api yang berada di stasiun sebelumnya dan di stasiun berikutnya.

      ART 74 -
        Ketentuan lebih lanjut mengenai tata cara kereta api dalam perjalanan dan perjalanan kereta api di jalur bergigi diatur dengan peraturan Menteri.

    PART Kesembilan - Kedatangan Kereta Api di Stasiun

      SUBPART 1 - Kereta Api Memasuki Stasiun

        ART 75 -
          PARA (1)
            Pada waktu kereta api akan masuk stasiun operasi, masinis wajib mematuhi indikasi sinyal masuk, indikasi sinyal muka, atau indikasi sinyal pendahulu.

          PARA (2)
            Masinis menjalankan kereta api memasuki stasiun sesuai dengan kecepatan yang diizinkan apabila sinyal masuk, sinyal muka, atau sinyal pendahulu menunjukkan indikasi aman.

          PARA (3)
            Masinis wajib mengurangi kecepatan untuk mempersiapkan kereta api berhenti di muka sinyal masuk apabila sinyal muka menunjukkan indikasi hatihati.

          PARA (4)
            Masinis wajib memberhentikan kereta api di muka sinyal masuk apabila sinyal masuk menunjukkan indikasi tidak aman.

          PARA (5)
            Dalam hal sinyal masuk sebagaimana dimaksud pada ayat (4) menunjukkan indikasi hati-hati, kereta api dapat berjalan terus memasuki stasiun untuk berhenti.

        ART 76 -
          Kereta api yang berhenti di muka sinyal masuk sebagaimana dimaksud dalam Pasal 75 ayat (4) dapat berjalan kembali setelah sinyal masuk mengindikasikan aman.

        ART 77 -
          Ketentuan lebih lanjut mengenai tata cara kereta api memasuki stasiun diatur dengan peraturan Menteri.

      SUBPART 2 - Menerima Kedatangan Kereta Api Berhenti

        ART 78 -
          PARA (1)
            Petugas pengatur perjalanan kereta api setempat yang akan menerima kedatangan kereta api sebelum memberi warta aman, wajib melakukan persiapan menerima kedatangan kereta api berhenti.

          PARA (2)
            Persiapan menerima kedatangan kereta api berhenti sebagaimana dimaksud pada ayat (1) meliputi kegiatan: a. menyiapkan pegawai stasiun; dan b. menyiapkan rute kereta api datang.

          PARA (3)
            Setelah melakukan persiapan sebagaimana dimaksud pada ayat (2) petugas pengatur perjalanan kereta api memberi warta aman kepada petugas pengatur perjalanan kereta api stasiun pemberangkatan dan menerima warta berangkat dari petugas pengatur perjalanan kereta api stasiun pemberangkatan.

          PARA (4)
            Menjelang kereta api masuk stasiun sampai kereta api keluar stasiun, petugas pengatur perjalanan kereta api harus mengawasi kedatangan kereta api dan kedudukan wesel.

        ART 79 -
          Ketentuan lebih lanjut mengenai tata cara menerima kedatangan kereta api berhenti diatur dengan peraturan Menteri.

      SUBPART 3 - Kereta Api Berhenti dan Berjalan Langsung di Stasiun

        ART 80 -
          PARA (1)
            Kereta api berhenti dan berjalan langsung di stasiun sesuai dengan Gapeka.

          PARA (2)
            Kereta api berhenti sebagaimana dimaksud pada ayat (1) dapat berjalan kembali setelah mendapat perintah berangkat dari petugas pengatur perjalanan kereta api.

          PARA (3)
            Kereta api berjalan langsung sebagaimana dimaksud pada ayat (1) apabila sinyal masuk dan sinyal keluar menunjukkan indikasi aman.

        ART 81 -
          Petugas pengatur perjalanan kereta api setempat harus melaporkan setiap kedatangan dan keberangkatan kereta api kepada petugas pengendali perjalanan kereta api.

        ART 82 -
          Ketentuan lebih lanjut mengenai tata cara kereta api berhenti dan berjalan langsung di stasiun diatur dengan peraturan Menteri

      SUBPART 4 - Kereta Api Berhenti di Stasiun Akhir

        ART 83 -
          PARA (1)
            Setelah kereta api berhenti di stasiun tujuan akhir harus dilakukan kegiatan penghapusan pendinasan kereta api.

          PARA (2)
            Kegiatan penghapusan pendinasan kereta api sebagaimana dimaksud pada ayat (1) meliputi:

            POINT a.
              melapor dan menyerahkan dokumen perjalanan kereta api kepada petugas pengatur perjalanan kereta api atau pembantu petugas pengatur perjalanan kereta api oleh awak sarana perkeretaapian;

            POINT b.
              melepas tanda akhiran kereta api di ujung belakang rangkaian kereta api oleh teknisi;

            POINT c.
              melepas alat perangkai dan saluran rem di antara lokomotif dan rangkaian gerbong dan/atau kereta oleh teknisi;

            POINT d.
              melangsir rangkaian kereta api menjadi beberapa bagian untuk proses pembongkaran, pemuatan, pemeliharaan, dan kegiatan lainnya oleh teknisi apabila diperlukan;

            POINT e.
              menempatkan kereta atau gerbong di jalan rel yang ditentukan oleh petugas pengatur perjalanan kereta api; dan

            POINT f.
              menempatkan rangkaian di jalur yang aman untuk persiapan perjalanan kereta api selanjutnya oleh petugas pengatur perjalanan kereta api.

        ART 84 -
          Ketentuan lebih lanjut mengenai tata cara kereta api berhenti di stasiun akhir diatur dengan peraturan Menteri.

    PART Kesepuluh - Keterlambatan Kereta Api

      ART 85 -
        PARA (1)
          Perjalanan kereta api harus sesuai dengan jadwal yang telah ditentukan dalam Gapeka.

        PARA (2)
          Dalam hal terjadi keterlambatan jadwal perjalanan kereta api yang melebihi batas toleransi waktu operasi yang diizinkan, penyelenggara prasarana perkeretaapian mengambil langkah-langkah untuk mengurangi keterlambatan perjalanan kereta api.

        PARA (3)
          Pedoman pelaksanaan untuk mengurangi keterlambatan perjalanan kereta api sebagaimana dimaksud pada ayat (2) meliputi karakterisitik dan jenis fasilitas operasi pada jaringan ditetapkan oleh Menteri.

    PART Kesebelas - Persilangan dan Penyusulan serta Penutupan dan Pembukaan Stasiun

      ART 86 -
        PARA (1)
          Persilangan atau penyusulan antarkereta api dilakukan di stasiun operasi atau tempat yang terdapat fasilitas untuk itu yang telah ditentukan sesuai dengan Gapeka.

        PARA (2)
          Dalam hal terjadi keterlambatan kereta api, persilangan atau penyusulan sebagaimana dimaksud pada ayat (1) dapat dipindahkan ke stasiun operasi lain atau tempat yang terdapat fasilitas untuk itu oleh petugas pengendali perjalanan kereta api dan dilaksanakan oleh petugas pengatur perjalanan kereta api.

      ART 87 -
        PARA (1)
          Stasiun operasi dapat dibuka atau ditutup sesuai kebutuhan pelayanan perjalanan kereta api berdasarkan Gapeka.

        PARA (2)
          Pembukaan atau penutupan stasiun operasi sebagaimana dimaksud pada ayat (1) dilakukan dalam hal:

          POINT a.
            kebutuhan operasional pada saat itu tidak dibutuhkan; dan/atau

          POINT b.
            untuk efisiensi.

      ART 88 -
        Ketentuan lebih lanjut mengenai tata cara persilangan dan penyusulan serta penutupan dan pembukaan stasiun operasi diatur dengan peraturan Menteri.

    PART Keduabelas - Kereta Api Berhenti Luar Biasa

      ART 89 -
        PARA (1)
          Kereta api berhenti luar biasa apabila kereta api yang menurut Gapeka berjalan langsung di stasiun operasi karena sesuatu hal harus berhenti.

        PARA (2)
          Hal yang menyebabkan kereta api berhenti luar biasa sebagaimana dimaksud pada ayat (1) diantaranya adalah:

          POINT a.
            perpindahan persilangan dan penyusulan;

          POINT b.
            kerusakan pada prasarana atau sarana perkeretaapian;

          POINT c.
            perawatan prasarana perkeretaapian atau perbaikan sarana perkeretaapian;

          POINT d.
            keadaan yang akan membahayakan keselamatan perjalanan kereta api;

          POINT e.
            indikasi sabotase;

          POINT f.
            bencana alam;

          POINT g.
            huru-hara; dan

          POINT h.
            adanya sarana perkeretaapian yang tertinggal pada petak blok.

      ART 90 -
        Dalam hal masinis meyakini adanya keadaan sebagaimana dimaksud dalam Pasal 89 ayat (2) huruf b, huruf d, huruf f, huruf g, huruf h, atau terdapat benda yang menghalangi perjalanan kereta api, masinis harus menghentikan kereta api di luar stasiun tanpa harus menunggu perintah dari petugas pengatur perjalanan kereta api.

      ART 91 -
        Ketentuan lebih lanjut mengenai tata cara kereta api berhenti luar biasa diatur dengan peraturan Menteri.

    PART Ketigabelas - Penundaan Keberangkatan Kereta Api

      ART 92 -
        PARA (1)
          Keberangkatan kereta api dari stasiun dapat ditunda apabila:

          POINT a.
            terjadi kerusakan sarana kereta api; atau

          POINT b.
            alasan teknis operasi.

        PARA (2)
          Dalam hal penundaan perjalanan kereta api penumpang antarkota yang memiliki waktu tempuh lebih dari 6 (enam) jam, terjadi penundaan berangkat yang diperkirakan akan berlangsung 3 (tiga) jam atau lebih, penyelenggara sarana perkeretaapian harus menyediakan kompensasi.

        PARA (3)
          Ketentuan lebih lanjut mengenai tata cara penundaan keberangkatan kereta api diatur dengan peraturan Menteri.

      ART 93 -
        Penyelenggara prasarana perkeretaapian dan/atau penyelenggara sarana perkeretaapian harus mengumumkan penundaan kereta api kepada pengguna jasa sebelum jadwal pemberangkatan kereta api.

    PART Keempatbelas - Pembatalan Keberangkatan Kereta Api

      ART 94 -
        PARA (1)
          Pembatalan keberangkatan kereta api dapat dilakukan apabila:

          POINT a.
            tidak ada angkutan;

          POINT b.
            alasan teknis operasi; atau

          POINT c.
            terjadi penundaan keberangkatan paling banyak 2 (dua) kali.

        PARA (2)
          Dalam hal pembatalan keberangkatan kereta api penumpang antarkota yang memiliki waktu tempuh lebih dari 6 (enam) jam, penyelenggara sarana perkeretaapian harus menyediakan kereta api atau moda angkutan darat lainnya sebagai pengganti dengan kelas pelayanan yang sama.

      ART 95 -
        Penyelenggara sarana perkeretaapian harus mengumumkan pembatalan kereta api kepada masyarakat atau pengguna jasa sebelum jadwal pemberangkatan kereta api.

      ART 96 -
        Ketentuan lebih lanjut mengenai tata cara pembatalan perjalanan kereta api diatur dengan peraturan Menteri.

    PART Kelimabelas - Pengalihan Perjalanan Kereta Api

      ART 97 -
        Perjalanan kereta api dapat dialihkan apabila terjadi rintang jalan pada jalur kereta api yang akan dilalui dan diperkirakan waktu yang diperlukan untuk mengatasi rintang jalan melebihi atau sama dengan waktu tempuh perjalanan kereta api pada jalur kereta api yang akan dialihkan.

      ART 98 -
        Penyelenggara sarana perkeretaapian harus mengumumkan pengalihan perjalanan kereta api kepada pengguna jasa.

    PART Keenambelas - Bagian Kereta Api yang Terputus

      ART 99 -
        PARA (1)
          Masinis kereta api yang mengetahui rangkaian bagian belakang terputus dalam perjalanan harus merangkaikan kembali kereta api dengan memperhatikan keselamatan dan keamanan perjalanan kereta api.

        PARA (2)
          Masinis wajib melaporkan kejadian terputusnya rangkaian dalam perjalanan kepada petugas pengatur perjalanan kereta api di stasiun operasi berikutnya untuk dilakukan pemeriksaan atau tindakan lain yang diperlukan.

      ART 100 -
        PARA (1)
          Dalam keadaan tertentu masinis dapat meninggalkan bagian rangkaian kereta api pada satu petak blok.

        PARA (2)
          Pada bagian rangkaian kereta api yang ditinggalkan sebagaimana dimaksud pada ayat (1) harus dipasang tanda tidak aman dan tanda bahaya di ujung belakang dan depan bagian rangkaian kereta api yang diletakkan pada jarak aman sehingga mudah terlihat oleh masinis lokomotif penolong.

        PARA (3)
          Masinis melanjutkan perjalanan kereta api tanpa tanda akhiran rangkaian dan membunyikan tanda bahaya berulang-ulang sampai kereta api berhenti di stasiun operasi berikutnya.

      ART 101 -
        PARA (1)
          Petugas pengatur perjalanan kereta api yang menerima laporan masinis sebagaimana dimaksud dalam Pasal 99 ayat (2) harus:

          POINT a.
            menyatakan dan memberitahukan petak blok tidak aman kepada petugas pengatur perjalanan kereta api stasiun operasi pemberangkatan sebelumnya; dan

          POINT b.
            meminta bantuan kepada petugas pengendali perjalanan kereta api untuk menarik bagian rangkaian kereta api yang ditinggal di petak blok.

        PARA (2)
          Setelah petak blok sebagaimana dimaksud pada ayat (1) huruf a dinyatakan aman, petugas pengatur perjalanan kereta api memberitahukan kepada petugas pengatur perjalanan kereta api stasiun operasi pemberangkatan sebelumnya.

      ART 102 -
        Kereta api dengan rangkaian terputus bagian belakang selama dalam perjalanan dan tidak diketahui oleh masinis, pengamanannya dibedakan dalam:

        POINT a.
          sistem persinyalan mekanis; dan

        POINT b.
          sistem persinyalan elektris.

      ART 103 -
        PARA (1)
          Petugas pengatur perjalanan kereta api yang mengetahui kereta api yang melintas tanpa tanda akhiran dalam sistem persinyalan mekanis sebagaimana dimaksud dalam Pasal 102 huruf a yang tidak diketahui oleh masinis, harus:

          POINT a.
            memberitahukan kepada petugas pengatur perjalanan kereta api pada stasiun operasi berikutnya yang akan dilewati agar kereta api diberhentikan luar biasa;

          POINT b.
            memberitahukan kepada petugas pengatur perjalanan kereta api di stasiun operasi sebelumnya agar mengambil tindakan pengamanan terhadap kemungkinan bagian rangkaian kereta api yang terputus;

          POINT c.
            berusaha menghentikan bagian rangkaian kereta api yang terputus apabila terdapat bagian rangkaian kereta api yang terputus berjalan terus memasuki wilayah stasiun operasi; dan

          POINT d.
            membunyikan genta tanda bahaya yang berada pada perlintasan atau menginformasikan kepada petugas penjaga perlintasan untuk menutup pintu perlintasan sampai bagian rangkaian kereta api yang terputus melewati perlintasan.

        PARA (2)
          Apabila tindakan pengamanan yang dilakukan petugas pengatur perjalanan kereta api sebelumnya sebagaimana dimaksud pada ayat (1) huruf b tidak berhasil, petugas pengatur perjalanan kereta api pada stasiun tersebut memberitahukan kepada petugas pengatur perjalanan kereta api stasiun operasi sebelumnya untuk mengambil tindakan sebagaimana dimaksud pada ayat (1) huruf c dan huruf d.

        PARA (3)
          Apabila usaha menghentikan sebagaimana dimaksud pada ayat (1) huruf c tidak berhasil, pengatur perjalanan kereta api harus memberitahukan kepada petugas pengatur perjalanan kereta api stasiun operasi berikutnya agar berusaha menghentikannya.

      ART 104 -
        PARA (1)
          Bagian rangkaian kereta api yang terputus dan tidak diketahui masinis dalam sistem persinyalan elektris sebagaimana dimaksud dalam Pasal 102 huruf b, setelah kereta api melewati petak blok dan dalam indikator petak blok masih menunjukkan indikasi terisi, petugas pengatur perjalanan kereta api di stasiun operasi berikutnya harus menghentikan kereta api dan memberitahukan kepada masinis mengenai ketidakutuhan rangkaian.

        PARA (2)
          Dalam hal petugas pengatur perjalanan kereta api sebagaimana dimaksud pada ayat (1) tidak dapat menghentikan kereta api, petugas pengatur perjalanan kereta api yang bersangkutan harus memberitahukan kepada petugas pengatur perjalanan kereta api pada stasiun kereta api sebelumnya untuk melakukan tindakan sebagaimana dimaksud dalam Pasal 103 huruf c dan huruf d.

      ART 105 -
        Ketentuan lebih lanjut mengenai tata cara penanganan bagian kereta api yang terputus diatur dengan peraturan Menteri.

    PART Ketujuhbelas - Rintang Jalan

      ART 106 -
        PARA (1)
          Penyelenggara prasarana perkeretaapian harus menjaga petak blok dari rintang jalan.

        PARA (2)
          Rintang jalan sebagaimana dimaksud pada ayat (1) dapat disebabkan oleh:

          POINT a.
            peristiwa alam;

          POINT b.
            kecelakaan;

          POINT c.
            gangguan prasarana perkeretaapian; dan/atau

          POINT d.
            sebab lain yang mengancam keselamatan perjalanan kereta api.

        PARA (3)
          Dalam hal terjadi rintang jalan sebagaimana dimaksud pada ayat (2) harus segera dilakukan tindakan:

          POINT a.
            penyelenggara prasarana perkeretaapian wajib mengumumkan kepada masyarakat dan pengguna jasa;

          POINT b.
            penyelenggara sarana perkeretaapian memindahkan penumpang, bagasi, dan barang hantaran ke kereta api lain atau moda angkutan lainnya sesuai dengan ketentuan yang berlaku agar perjalanan penumpang dan/atau barang tetap lancar; dan

          POINT c.
            petugas pengatur perjalanan kereta api menghentikan semua kereta api di stasiun terdekat.

        PARA (4)
          Dalam hal rintang jalan sebagaimana dimaksud pada ayat (1) terjadi pada salah satu jalur pada jalur ganda penyelenggara prasarana perkeretaapian dan penyelenggara sarana perkeretaapian dapat menggunakan jalur sebelahnya yang tidak terkena rintang jalan.

      ART 107 -
        Ketentuan lebih lanjut mengenai tata cara penanganan rintang jalan diatur dengan peraturan Menteri.

    PART Kedelapanbelas - Langsiran

      ART 108 -
        PARA (1)
          Kegiatan langsiran dilakukan untuk:

          POINT a.
            menyusun rangkaian kereta api;

          POINT b.
            menambah atau mengurangi rangkaian;

          POINT c.
            menghapuskan pendinasan kereta api; atau

          POINT d.
            keperluan bongkar muat.

        PARA (2)
          Langsiran sebagaimana dimaksud pada ayat (1) dapat dilakukan di stasiun atau di tempat lain dengan ketentuan tidak mengganggu perjalanan kereta api.

        PARA (3)
          Langsiran dilakukan oleh petugas langsir setelah mendapat perintah petugas pengatur perjalanan kereta api.

        PARA (4)
          Pelaksanaan langsiran sebagaimana dimaksud pada ayat (3) harus dipandu dan dibantu oleh petugas langsir serta dikendalikan oleh petugas pengatur perjalanan kereta api.

      ART 109 -
        Ketentuan lebih lanjut mengenai tata cara langsiran diatur dengan peraturan Menteri.

    PART Kesembilanbelas - Kewajiban Mendahulukan Perjalanan Kereta Api

      ART 110 -
        PARA (1)
          Pada perpotongan sebidang antara jalur kereta api dengan jalan yang selanjutnya disebut dengan perpotongan sebidang yang digunakan untuk lalu lintas umum atau lalu lintas khusus, pemakai jalan wajib mendahulukan perjalanan kereta api.

        PARA (2)
          Pemakai jalan wajib mematuhi semua rambu-rambu jalan di perpotongan sebidang.

        PARA (3)
          Dalam hal terjadi pelanggaran sebagaimana dimaksud pada ayat (1) dan ayat (2) yang menyebabkan kecelakaan, maka hal ini bukan merupakan kecelakaan perkeretaapian.

        PARA (4)
          Pintu perlintasan pada perpotongan sebidang berfungsi untuk mengamankan perjalanan kereta api.

  CHAPTER IV -

    PART Kesatu - Awak Sarana Perkeretaapian

      ART 111 -
        PARA (1)
          Pengoperasian kereta api antarkota dan kereta api perkotaan dilakukan oleh awak sarana perkeretaapian.

        PARA (2)
          Awak sarana perkeretaapian sebagaimana dimaksud pada ayat (1) mengoperasikan sarana perkeretaapian berdasarkan surat perintah tugas dari penyelenggara sarana perkeretaapian.

        PARA (3)
          Awak sarana perkeretaapian yang mengoperasikan kereta api yang tidak memiliki surat perintah tugas sebagaimana dimaksud pada ayat (2), dikenai sanksi administratif berupa teguran tertulis, pembekuan sertifikat kecakapan, atau pencabutan sertifikat kecakapan.

        PARA (4)
          Pembekuan sertifikat kecakapan sebagaimana dimaksud pada ayat (3) diberikan setelah dilakukan teguran tertulis sebanyak 3 (tiga) kali atau mengakibatkan kecelakaan yang tidak menimbulkan korban jiwa.

        PARA (5)
          Pencabutan sertifikat kecakapan sebagaimana dimaksud pada ayat (3) dilakukan apabila awak sarana perkeretaapian pernah dibekukan sertifikatnya sebanyak 3 (tiga) kali atau mengakibatkan kecelakaan yang menimbulkan korban jiwa.

      ART 112 -
        PARA (1)
          Awak sarana perkeretaapian sebagaimana dimaksud dalam Pasal 111 terdiri atas:

          POINT a.
            masinis; dan

          POINT b.
            asisten masinis.

        PARA (2)
          Pengoperasian kereta api antarkota, masinis dibantu oleh asisten masinis.

        PARA (3)
          Pengoperasian kereta api perkotaan, masinis dapat dibantu oleh asisten masinis.

      ART 113 -
        Masinis bertindak sebagai pemimpin selama dalam perjalanan kereta api.

      ART 114 -
        PARA (1)
          Masinis dalam mengoperasikan kereta api antarkota atau kereta api perkotaan, harus berdasarkan Gapeka.

        PARA (2)
          Masinis dalam mengoperasikan kereta api antarkota dan kereta api perkotaan sebagaimana dimaksud pada ayat (1), wajib mematuhi perintah atau larangan petugas pengatur perjalanan kereta api, sinyal, tanda, dan marka.

        PARA (3)
          Apabila terdapat lebih dari satu perintah atau larangan dalam waktu yang bersamaan, masinis dan asisten masinis wajib mematuhi perintah atau larangan yang diberikan berdasarkan prioritas sebagai berikut:

          POINT a.
            petugas pengatur perjalanan kereta api;

          POINT b.
            sinyal; dan

          POINT c.
            tanda dan marka.

        PARA (4)
          Masinis bertanggung jawab terhadap perjalanan kereta api.

      ART 115 -
        PARA (1)
          Awak sarana perkeretaapian sebagaimana dimaksud dalam Pasal 112 ayat (1), dapat dibantu oleh kondektur, teknisi, dan/atau petugas lainnya.

        PARA (2)
          Kondektur, teknisi, dan/atau petugas lainnya sebagaimana dimaksud pada ayat (1) dalam menjalankan tugasnya berdasarkan penugasan dari penyelenggara sarana perkeretaapian.

      ART 116 -
        Kondektur sebagaimana dimaksud dalam Pasal 115 ayat (1) bertugas:

        POINT a.
          menyiapkan dan membuat dokumen perjalanan kereta api;

        POINT b.
          memeriksa dan menertibkan penumpang dan barang;

        POINT c.
          membantu awak sarana perkeretaapian dalam pemberangkatan kereta api;

        POINT d.
          memandu jalannya kereta api dengan kecepatan terbatas apabila terjadi gangguan pada prasarana dan/atau sarana kereta api; dan

        POINT e.
          mengoordinasikan pelaksanaan tugas petugas lain yang bekerja di kereta api.

      ART 117 -
        Teknisi sebagaimana dimaksud dalam Pasal 115 ayat (1) bertugas:

        POINT a.
          melakukan perbaikan ringan peralatan atau fasilitas sarana perkeretaapian dan/atau sarana perkeretaapian; dan

        POINT b.
          mengoperasikan fasilitas sarana perkeretaapian.

      ART 118 -
        Kondektur dan teknisi selain bertugas sebagaimana dimaksud dalam Pasal 116 dan Pasal 117 juga harus membantu masinis dalam perjalanan kereta api.

      ART 119 -
        Ketentuan lebih lanjut mengenai tata cara pengaturan awak sarana perkeretaapian diatur dengan peraturan Menteri.

    PART Kedua - Angkutan

      SUBPART 1 - Umum

        ART 120 -
          Jenis angkutan dengan kereta api terdiri atas:

          POINT a.
            angkutan orang; dan

          POINT b.
            angkutan barang

      SUBPART 2 - Angkutan Orang

        ART 121 -
          PARA (1)
            Penyelenggara sarana perkeretaapian wajib mengangkut orang yang telah memiliki karcis.

          PARA (2)
            Orang yang telah memiliki karcis berhak memperoleh pelayanan sesuai dengan tingkat pelayanan yang dipilih.

          PARA (3)
            Karcis sebagaimana dimaksud pada ayat (1) merupakan tanda bukti terjadinya perjanjian angkutan orang.

        ART 122 -
          Karcis sebagaimana dimaksud dalam Pasal 121 ayat (1) paling sedikit memuat informasi:

          POINT a.
            kelas pelayanan;

          POINT b.
            nama stasiun pemberangkatan dan stasiun tujuan;

          POINT c.
            tanggal dan waktu pemberangkatan serta kedatangan; dan

          POINT d.
            harga karcis.

        ART 123 -
          Penumpang anak yang berumur kurang dari 3 (tiga) tahun tidak dikenai biaya apabila tidak mengambil tempat duduk.

        ART 124 -
          Setiap orang dilarang masuk ke dalam peron stasiun, kecuali petugas, penumpang yang memiliki karcis, dan pengantar/penjemput yang memiliki karcis peron.

        ART 125 -
          PARA (1)
            Penumpang yang membawa barang harus meletakkan barang bawaannya di tempat yang ditentukan untuk meletakkan barang.

          PARA (2)
            Dalam hal barang bawaan sebagaimana dimaksud pada ayat (1) diletakkan dalam kereta bagasi, barang bawaan dikenai biaya angkutan.

          PARA (3)
            Biaya angkutan sebagaimana dimaksud pada ayat (2) ditentukan berdasarkan tarif yang ditetapkan oleh penyelenggara sarana perkeretaapian.

        ART 126 -
          PARA (1)
            Atas persetujuan penyelenggara sarana perkeretaapian, penumpang diperbolehkan membawa binatang peliharaan dengan syarat:

            POINT a.
              bebas penyakit;

            POINT b.
              tidak memakan tempat;

            POINT c.
              tidak mengganggu kenyamanan penumpang lain; dan

            POINT d.
              dimasukkan dalam tempat khusus.

          PARA (2)
            Tanggung jawab terhadap binatang peliharaan yang dibawa penumpang sepenuhnya menjadi tanggung jawab penumpang yang bersangkutan.

        ART 127 -
          PARA (1)
            Setiap orang naik atau berada di dalam kereta api dilarang:

            POINT a.
              dalam keadaan mabuk;

            POINT b.
              membawa barang berbahaya;

            POINT c.
              membawa barang terlarang;

            POINT d.
              berperilaku yang dapat membahayakan keselamatan dan atau mengganggu penumpang lain;

            POINT e.
              berjudi atau melakukan perbuatan asusila; dan/atau

            POINT f.
              membahayakan perjalanan kereta api.

          PARA (2)
            Orang yang melanggar larangan sebagaimana dimaksud pada ayat (1) harus diturunkan di stasiun terdekat berikutnya.

        ART 128 -
          PARA (1)
            Orang yang tidak memiliki karcis dilarang naik kereta api kecuali orang yang ditugaskan oleh penyelenggara sarana perkeretaapian.

          PARA (2)
            Penyelenggara sarana perkeretaapian dapat menurunkan orang yang tidak memiliki karcis di stasiun terdekat dan/atau mengenakan denda paling banyak sebesar:

            POINT a.
              500% (lima ratus per seratus) dari harga karcis untuk angkutan kereta api perkotaan; atau

            POINT b.
              200% (dua ratus per seratus) dari harga karcis untuk angkutan kereta api antarkota.

        ART 129 -
          PARA (1)
            Penumpang yang memiliki karcis dengan kelas pelayanan yang lebih rendah dari kereta api yang dinaiki, penyelenggara sarana perkeretaapian dapat mengenakan sanksi berupa denda dengan membayar harga karcis dari stasiun pemberangkatan awal ke stasiun tujuan akhir atau menurunkan di stasiun terdekat.

          PARA (2)
            Penumpang yang memiliki karcis tidak sesuai dengan jurusan kereta api yang dinaiki, penyelenggara sarana perkeretaapian dapat mengenakan sanksi sebagaimana dimaksud dalam Pasal 128 ayat (2).

          PARA (3)
            Penumpang yang memiliki karcis dengan kelas pelayanan yang lebih rendah dalam 1 (satu) rangkaian kereta api, penyelenggara sarana perkeretaapian dapat mengenakan sanksi berupa denda dengan membayar kekurangan harga karcis atau menurunkan di stasiun terdekat.

        ART 130 -
          PARA (1)
            Pengangkutan orang dengan kereta api harus dilakukan dengan menggunakan kereta.

          PARA (2)
            Dalam keadaan tertentu penyelenggara sarana perkeretaapian dapat melakukan pengangkutan orang dengan menggunakan gerbong dan/atau kereta bagasi yang bersifat sementara dengan ketentuan:

            POINT a.
              kereta pada jalur yang bersangkutan tidak tersedia atau tidak mencukupi;

            POINT b.
              adanya permintaan angkutan yang mendesak; atau

            POINT c.
              keadaan darurat.

          PARA (3)
            Gerbong dan/atau kereta bagasi sebagaimana dimaksud pada ayat (2) harus tertutup dan memenuhi persyaratan keselamatan dan keamanan penumpang serta paling sedikit dilengkapi dengan fasilitas berupa:

            POINT a.
              pintu masuk/keluar;

            POINT b.
              ventilasi udara;

            POINT c.
              alas untuk duduk yang bersih; dan

            POINT d.
              penerangan.

        ART 131 -
          PARA (1)
            Penggunaan gerbong dan/atau kereta bagasi sebagaimana dimaksud dalam Pasal 130 ayat (2) huruf a dan huruf b dapat dilakukan atas persetujuan dari Menteri, gubernur, dan bupati/walikota sesuai dengan kewenangannya.

          PARA (2)
            Penggunaan gerbong dan/atau kereta bagasi untuk keadaan darurat sebagaimana dimaksud dalam Pasal 130 ayat (2) huruf c dilaporkan segera setelah penggunaan gerbong dan/atau kereta bagasi untuk mengangkut orang.

        ART 132 -
          Ketentuan lebih lanjut mengenai tata cara angkutan orang diatur dengan peraturan Menteri.

      SUBPART 3 - Standar Pelayanan Minimum Angkutan Orang

        ART 133 -
          PARA (1)
            Pengoperasian kereta api harus memenuhi standar pelayanan minimum.

          PARA (2)
            Standar pelayanan minimum sebagaimana dimaksud pada ayat (1) meliputi:

            POINT a.
              standar pelayanan minimum di stasiun kereta api; dan

            POINT b.
              standar pelayanan minimum dalam perjalanan.

        ART 134 -
          PARA (1)
            Standar pelayanan minimum di stasiun kereta api kelas besar sebagaimana dimaksud dalam Pasal 133 ayat (2) huruf a paling sedikit terdapat:

            POINT a.
              informasi yang jelas dan mudah dibaca mengenai:

              POINT 1.
                nama dan nomor kereta api;

              POINT 2.
                jadwal keberangkatan dan kedatangan kereta api;

              POINT 3.
                tarif kereta api;

        ART 137 -

          PARA (3)
            Pengangkutan kiriman pos dan jenazah sebagaimana dimaksud pada ayat (1) huruf b dan huruf c dapat menggunakan kereta bagasi.

        ART 138 -

              kendaraan;

            POINT h.
              alat berat;

            POINT i.

            POINT j.

          PARA (2)

          PARA (4)

          PARA (5)

          PARA (7)
            Pengangkutan hewan hidup sebagaimana dimaksud pada ayat (1) huruf f menggunakan gerbong hewan harus disediakan air dan makanan hewan, harus diikat dan/atau disekat serta dijaga seorang atau lebih pemelihara hewan.

            Pengangkutan kendaraan sebagaimana dimaksud pada ayat (1) huruf g menggunakan gerbong datar atau kereta bagasi.

          PARA (9)

        ART 140 -
          Angkutan limbah bahan berbahaya dan beracun sebagaimana dimaksud dalam Pasal 136 ayat (2) huruf d, dapat menggunakan gerbong terbuka, gerbong tertutup, atau gerbong khusus setelah dikemas sesuai dengan ketentuan peraturan perundang-undangan.

        ART 141 -
          PARA (1)
            Pengangkutan bahan berbahaya dan beracun, dan limbah bahan berbahaya dan beracun sebagaimana dimaksud dalam Pasal 139 ayat (2) dan Pasal 140 harus memenuhi syarat:

            POINT a.
              pengirim merupakan instansi yang berwenang atau pengguna jasa yang telah mendapat izin tertulis dari Menteri setelah mendapat rekomendasi dari instansi yang terkait;

            POINT b.
              bongkar muat dilakukan pada tempat dan/atau stasiun tertentu yang mempunyai fasilitas bongkar muat sesuai dengan kekhususan bahan yang diangkut;

            POINT c.
              diangkut dengan gerbong sesuai dengan jenis bahan yang diangkut dan diberikan tanda khusus;

            POINT d.
              dilakukan pengawalan dan/atau menyertakan petugas yang memiliki keterampilan dan kualifikasi tertentu sesuai sifat bahan berbahaya dan beracun yang diangkut;

            POINT e.
              petugas pengawal harus mengambil tindakan apabila terjadi hal-hal yang membahayakan keamanan dan keselamatan barang yang dibawa;

              antara 2 (dua) gerbong yang berisi harus ditempatkan gerbong kosong sebagai penyekat; dan

            POINT g.
              perjalanan kereta api menggunakan kecepatan sesuai dengan kecepatan yang ditetapkan.

          PARA (2)

        ART 142 -

          POINT a.
            berat barang yang dimuat tidak melebihi beban gandar untuk masing-masing gandar gerbong; dan

          POINT b.
            beban gandar gerbong yang dimuat barang tidak melebihi beban gandar jalur kereta api.

        ART 143 -
          Pemuatan dan pembongkaran barang dapat dilakukan di:

          POINT a.
            stasiun kereta api; atau

            tempat lain diluar stasiun kereta api yang diperuntukkan untuk bongkar dan muat barang yang ditetapkan oleh Menteri.

        ART 144 -
          PARA (1)

            POINT a.

            POINT c.
              tanggal dan waktu keberangkatan dan kedatangan;

            POINT d.
              jenis barang yang diangkut; dan

            POINT e.
              tarif yang disepakati.

        ART 145 -

    PART Ketiga - Tarif

      SUBPART 1 - Umum

        ART 146 -

      SUBPART 2 - Tarif Angkutan Orang

        ART 147 -
          PARA (1)
            Tarif angkutan orang sebagaimana dimaksud dalam Pasal 146 ayat (1) merupakan besaran biaya yang dinyatakan dalam biaya per penumpang per kilometer.

          PARA (2)
            Tarif angkutan orang sebagaimana dimaksud pada ayat (1) ditetapkan oleh penyelenggara sarana perkeretaapian.

          PARA (3)
            Tarif angkutan orang sebagaimana dimaksud pada ayat (1) wajib diumumkan oleh penyelenggara sarana perkeretaapian paling lambat 3 (tiga) bulan sebelum diberlakukan.

          PARA (4)
            Pengumuman tarif sebagaimana dimaksud pada ayat (3) dapat dilakukan di stasiun dan/atau media cetak/elektronik.

        ART 148 -
          PARA (1)
            Penyelenggara sarana perkeretaapian melaporkan tarif yang ditetapkan kepada Menteri, gubernur, atau bupati/walikota yang mengeluarkan izin operasi.

          PARA (2)
            Menteri, gubernur, atau bupati/walikota sesuai dengan kewenangannya melakukan evaluasi penetapan dan pelaksanaan tarif.

          PARA (3)
            Dalam hal penetapan dan pelaksanaan tarif oleh penyelenggara sarana perkeretaapian tidak sesuai dengan pedoman penetapan tarif yang ditetapkan oleh Menteri sebagaimana dimaksud dalam Pasal 146 ayat (2), Menteri, gubernur, atau bupati/walikota sesuai dengan kewenangannya dapat mengenakan sanksi administratif berupa:

            POINT a.
              teguran tertulis;

            POINT b.
              pembekuan izin operasi; dan

            POINT c.
              pencabutan izin operasi.

          PARA (4)
            Ketentuan lebih lanjut mengenai tata cara pengenaan sanksi administratif diatur dengan peraturan Menteri.

        ART 149 -
          PARA (1)
            Menteri, gubernur, atau bupati/walikota dapat menetapkan tarif angkutan apabila:

            POINT a.
              masyarakat belum mampu membayar tarif yang ditetapkan oleh Penyelenggara Sarana Perkeretaapian untuk angkutan pelayanan kelas ekonomi; atau

            POINT b.
              dalam rangka pertumbuhan daerah baru atau dalam rangka pemerataan, pertumbuhan, dan stabilitas pembangunan nasional yang secara ekonomis belum menguntungkan untuk angkutan perintis.

          PARA (2)
            Dalam hal tarif yang ditetapkan oleh Menteri, gubernur, atau bupati/walikota sebagaimana dimaksud pada ayat (1) huruf a lebih rendah dari tarif yang ditetapkan penyelenggara sarana perkeretaapian, selisih tarif menjadi tanggung jawab Menteri, gubernur, atau bupati/walikota dalam bentuk kewajiban pelayanan publik.

          PARA (3)
            Dalam hal Menteri, gubernur, atau bupati/walikota menugaskan kepada penyelenggara sarana perkeretaapian untuk menyelenggarakan angkutan perintis sebagaimana dimaksud pada ayat (1) huruf b, dan biaya yang dikeluarkan oleh penyelenggara sarana perkeretaapian lebih tinggi dari pendapatan yang diperoleh berdasarkan tarif yang ditetapkan oleh Menteri, gubernur, atau bupati/walikota, maka selisihnya menjadi tanggung jawab Menteri, gubernur, atau bupati/walikota, dalam bentuk subsidi angkutan perintis.

        ART 150 -
          Angkutan pelayanan kelas ekonomi dan angkutan perintis paling sedikit harus memenuhi standar pelayanan minimum sebagaimana dimaksud dalam Pasal 134 ayat (2).

        ART 151 -
          Menteri, gubernur, atau bupati/walikota sesuai dengan kewenangannya:

          POINT a.
            menetapkan lintas pelayanan untuk angkutan pelayanan kelas ekonomi dan angkutan perintis; dan

          POINT b.
            melakukan monitoring dan evaluasi terhadap pelayanan dan tarif yang dilaksanakan oleh penyelenggara sarana perkeretaapian.

        ART 152 -
          Ketentuan lebih lanjut mengenai tata cara perhitungan dan penetapan tarif angkutan orang diatur dengan peraturan Menteri.

        ART 153 -

        ART 154 -

      SUBPART 4 - Pembatalan Perjalanan

        ART 156 -
          PARA (1)
            Penyelenggara sarana perkeretaapian wajib mengembalikan jumlah biaya yang telah dibayar oleh penumpang atau pengirim barang apabila terjadi pembatalan pemberangkatan perjalanan kereta api oleh penyelenggara sarana perkeretaapian.

          PARA (2)
            Apabila pembatalan dilakukan di awal perjalanan, penyelenggara sarana perkeretaapian wajib mengembalikan seluruh biaya angkutan.

        ART 157 -
          PARA (1)
            Penumpang dapat membatalkan keberangkatan atas keinginan sendiri.

          PARA (2)
            Pembatalan sebagaimana dimaksud pada ayat (1), harus dilaporkan kepada penyelenggara sarana perkeretaapian paling lama 30 (tiga puluh) menit sebelum jadwal keberangkatan.

          PARA (3)
            Dalam hal pembatalan dilakukan 30 (tiga puluh) menit sebelum jadwal keberangkatan sebagaimana dimaksud pada ayat (2), penumpang mendapat pengembalian sebesar 75% (tujuh puluh lima per seratus) dari harga karcis.

          PARA (4)
            Dalam hal pembatalan dilakukan kurang dari 30 (tiga puluh) menit sebelum jadwal keberangkatan, penumpang tidak mendapat pengembalian harga karcis.

          PARA (5)
            Ketentuan lebih lanjut mengenai pembatalan keberangkatan diatur oleh penyelenggara sarana perkeretaapian

        ART 158 -
          PARA (1)
            Pengguna jasa angkutan barang dapat membatalkan pengiriman atas keinginan sendiri.

          PARA (2)
            Ketentuan mengenai pembatalan pengiriman barang diatur oleh penyelenggara sarana perkeretaapan.

      SUBPART 5 - Biaya Penggunaan Prasarana

        ART 159 -
          PARA (1)
            Apabila penyelenggara sarana perkeretaapian menggunakan prasarana perkeretaapian yang dimiliki atau dioperasikan oleh penyelenggara prasarana perkeretaapian, penyelenggara sarana perkeretaapian harus membayar biaya penggunaan prasarana perkeretaapian.

          PARA (2)
            Besarnya biaya penggunaan prasarana perkeretaapian sebagaimana dimaksud pada ayat (1) dihitung berdasarkan pedoman penetapan biaya penggunaan prasarana perkeretaapian yang ditetapkan oleh Menteri.

          PARA (3)
            Pedoman penetapan biaya penggunaan prasarana perkeretaapian sebagaimana dimaksud pada ayat (2) dihitung berdasarkan beban penggunaan prasarana yang berdampak pada biaya perawatan, biaya pengoperasian, dan penyusutan prasarana dengan memperhitungkan prioritas penggunaan prasarana perkeretaapian.

        ART 160 -
          Ketentuan lebih lanjut mengenai biaya penggunaan prasarana diatur dengan peraturan Menteri.

    PART Keempat - Angkutan Kereta Api Khusus

      ART 161 -
        PARA (1)
          Pelayanan angkutan perkeretaapian khusus hanya digunakan untuk menunjang kegiatan pokok badan usaha tertentu.

        PARA (2)
          Pelayanan angkutan perkeretaapian khusus sebagaimana dimaksud pada ayat (1) dapat diintegrasikan dengan jaringan pelayanan angkutan perkeretaapian umum dan jaringan pelayanan angkutan perkeretaapian khusus lainnya.

        PARA (3)
          Dalam hal terjadi integrasi sebagaimana dimaksud pada ayat (2) maka berlaku ketentuan pelayanan perkeretaapian umum.

        PARA (4)
          Dalam hal pelayanan angkutan perkeretaapian khusus diintegrasikan dengan jaringan pelayanan angkutan perkeretaapian umum sebagaimana dimaksud pada ayat (2), harus mendapat persetujuan dari:

          POINT a.
            Menteri, pada jaringan jalur perkeretaapian nasional;

          POINT b.
            gubernur, pada jaringan jalur perkeretaapian provinsi; atau

          POINT c.
            bupati/walikota, pada jaringan jalur perkeretaapian kabupaten/kota.

        PARA (5)
          Dalam hal pelayanan angkutan perkeretaapian khusus diintegrasikan dengan jaringan pelayanan perkeretaapian khusus lainnya sebagaimana dimaksud pada ayat (2), harus mendapat persetujuan dari:

          POINT a.
            Menteri, untuk pengintegrasian dengan jaringan pelayanan angkutan perkeretaapian khusus lainnya yang menghubungkan antarprovinsi;

          POINT b.
            gubernur, untuk pengintegrasian dengan jaringan pelayanan angkutan perkeretaapian khusus lainnya yang menghubungkan antarkabupaten/kota dalam 1 (satu) provinsi; atau

          POINT c.
            bupati/walikota, untuk pengintegrasian dengan jaringan pelayanan angkutan perkeretaapian khusus lainnya yang menghubungkan pelayanan dalam 1 (satu) kabupaten/kota.

      ART 162 -
        Pengintegrasian pelayanan angkutan kereta api khusus dengan jaringan pelayanan angkutan perkeretaapian umum dan/atau jaringan perkeretaapian khusus lainnya sebagaimana dimaksud dalam Pasal 161 dilaksanakan melalui kerja sama antara badan usaha perkeretaapian khusus dan penyelenggara prasarana perkeretaapian umum dan/atau badan usaha perkeretaapian khusus lainnya.

      ART 163 -
        Ketentuan lebih lanjut mengenai tata cara pemberian persetujuan pengintegrasian pelayanan angkutan perkeretaapian khusus diatur dengan peraturan Menteri.

    ART 165 -
      PARA (1)
        Menteri, gubernur, atau bupati/walikota melakukan evaluasi terhadap laporan sebagaimana dimaksud dalam Pasal 164 ayat (1).

      PARA (2)
        Hasil evaluasi sebagaimana dimaksud pada ayat (1) digunakan oleh Menteri, gubernur, atau bupati/walikota sebagai dasar untuk melakukan penilaian penyelenggaraan pelayanan oleh penyelenggara sarana perkeretaapian dan/atau penyelenggara prasarana perkeretaapian serta untuk menetapkan kebijakan dalam penyelenggaraan perkeretaapian.

    ART 166 -
      Apabila penyelenggara sarana perkeretaapian dan/atau penyelenggara prasarana perkeretaapian tidak menyampaikan laporan sebagaimana dimaksud dalam Pasal 165 dikenai sanksi administrasi berupa:

      POINT a.
        teguran tertulis;

      POINT b.
        pembekuan izin operasi; dan

      POINT c.
        pencabutan izin operasi.

    ART 167 -
      Ketentuan lebih lanjut mengenai tata cara pelaporan dan pengenaan sanksi administratif penyelenggaraan angkutan kereta api diatur dengan peraturan Menteri.

  CHAPTER VI -

    PART Kesatu - Tanggung Jawab Terhadap Penumpang yang Diangkut

      ART 168 -
        PARA (1)
          Penyelenggara sarana perkeretaapian bertanggung jawab terhadap penumpang yang mengalami kerugian, lukaluka, atau meninggal dunia yang disebabkan oleh pengoperasian angkutan kereta api.

        PARA (2)
          Tanggung jawab sebagaimana dimaksud pada ayat (1) berupa:

          POINT a.
            pemberian ganti kerugian dan biaya pengobatan bagi penumpang yang luka-luka; dan

          POINT b.
            santunan bagi penumpang yang meninggal dunia.

        PARA (3)
          Tanggung jawab sebagaimana dimaksud pada ayat (2) dimulai sejak penumpang diangkut dari stasiun asal sampai dengan stasiun tujuan yang tercantum dalam karcis.

      ART 169 -
        PARA (1)
          Penumpang yang mengalami kerugian, luka-luka, dan keluarga dari penumpang yang meninggal dunia sebagai akibat pengoperasian angkutan kereta api harus memberitahukan kepada penyelenggara sarana perkeretaapian paling lama 12 (dua belas) jam terhitung sejak kejadian.

        PARA (2)
          Pemberitahuan sebagaimana dimaksud pada ayat (1) disampaikan kepada penyelenggara sarana melalui awak sarana perkeretaapian atau petugas pengatur perjalanan kereta api pada stasiun terdekat dengan menunjukkan karcis.

      ART 170 -
        PARA (1)
          Dalam hal penumpang yang mengalami kerugian, lukaluka, dan keluarga dari penumpang yang meninggal dunia sebagaimana dimaksud dalam Pasal 169 ayat (1) tidak dapat memberitahukan kepada penyelenggara sarana perkeretaapian, penyelenggara sarana perkeretaapian wajib memberitahukan kepada keluarga dari penumpang yang mengalami kerugian, luka-luka, atau meninggal dunia sebagai akibat pengoperasian angkutan kereta api.

        PARA (2)
          Penyelenggara sarana perkeretaapian segera memberikan ganti kerugian dan biaya pengobatan bagi penumpang yang luka-luka atau santunan penumpang yang meninggal dunia.

        PARA (3)
          Ganti kerugian dan biaya pengobatan bagi penumpang yang luka-luka atau santunan penumpang yang meninggal dunia sebagaimana dimaksud pada ayat (2) wajib dipenuhi oleh penyelenggara sarana perkeretaapian paling lama 30 (tiga puluh) hari sejak kejadian.

      ART 171 -
        PARA (1)
          Penyelenggara sarana perkeretaapian tidak bertanggung jawab terhadap kerugian yang diderita oleh pihak ketiga yang disebabkan oleh pengoperasian angkutan kereta api, kecuali jika pihak ketiga dapat membuktikan bahwa kerugian disebabkan oleh kesalahan penyelenggara sarana perkeretaapian atau orang yang dipekerjakan oleh penyelenggara sarana perkeretaapian di atas kereta api.

        PARA (2)
          Hak untuk mengajukan keberatan dan permintaan ganti kerugian sebagaimana dimaksud pada ayat (1) disampaikan paling lama 30 (tiga puluh) hari terhitung mulai tanggal terjadinya kerugian.

      ART 172 -
        Penyelenggara sarana perkeretaapian ikut bertanggung jawab terhadap segala perbuatan yang merugikan penumpang yang dilakukan oleh orang yang dipekerjakan secara sah selama pengoperasian kereta api.

      ART 173 -
        Ketentuan lebih lanjut mengenai tata cara pemberian santunan, pengobatan, dan besarnya ganti kerugian terhadap penumpang dan pihak ketiga diatur dengan peraturan Menteri.

    PART Kedua - Tanggung Jawab terhadap Barang yang Diangkut

      ART 174 -
        PARA (1)
          Penyelenggara sarana perkeretaapian bertanggung jawab mengganti kerugian yang ditimbulkan karena kelalaian penyelenggara sarana perkeretaapian dalam pengoperasian angkutan kereta api.

        PARA (2)
          Kerugian sebagaimana dimaksud pada ayat (1) dapat berupa:

          POINT a.
            barang hilang sebagian atau seluruhnya;

          POINT b.
            rusak sebagian atau seluruhnya;

          POINT c.
            musnah;

          POINT d.
            salah kirim; dan/atau

          POINT e.
            jumlah dan/atau jenis kiriman barang diserahkan dalam keadaan tidak sesuai dengan surat angkutan.

        PARA (3)
          Besarnya ganti kerugian dihitung berdasarkan kerugian yang nyata-nyata dialami, tidak termasuk keuntungan yang akan diperoleh dan biaya jasa yang telah digunakan.

      ART 175 -
        PARA (1)
          Pada saat barang tiba di tempat tujuan, penyelenggara sarana perkeretaapian segera memberitahukan kepada penerima barang bahwa barang telah tiba dan dapat segera diambil.

        PARA (2)
          Apabila dalam jangka waktu 7 (tujuh) hari kalender terhitung sejak barang tiba di tempat tujuan penyelenggara sarana perkeretaapian tidak memberitahukan kepada penerima barang sebagaimana dimaksud pada ayat (1), pengguna jasa atau penerima barang berhak mengajukan klaim ganti kerugian.

        PARA (3)
          Pengajuan klaim ganti kerugian sebagaimana dimaksud pada ayat (2) harus disampaikan kepada penyelenggara sarana perkeretaapian dimulai sejak 7 (tujuh) hari kalender sejak diberikannya hak pengajuan klaim ganti kerugian.

        PARA (4)
          Apabila penerima barang tidak mengajukan klaim ganti kerugian dalam jangka waktu sebagaimana dimaksud pada ayat (3), hak untuk mengajukan klaim ganti kerugian kepada penyelenggara sarana perkeretaapian menjadi gugur.

      ART 176 -
        Pihak penerima barang yang tidak menyampaikan keberatan pada saat menerima barang dari penyelenggara sarana perkeretaapian, dianggap telah menerima barang dalam keadaan baik.

      ART 177 -
        Penyelenggara sarana perkeretaapian dibebaskan dari tanggung jawab mengganti kerugian apabila:

        POINT a.
          penerima barang terlambat dan/atau lalai mengambil barang setelah diberitahukan oleh penyelenggara sarana perkeretaapian;

        POINT b.
          kerugian tidak disebabkan kelalaian dalam pengoperasian angkutan kereta api oleh penyelenggara sarana perkeretaapian; dan

        POINT c.
          kerugian yang disebabkan oleh keterangan yang tidak benar dalam surat angkutan barang.

      ART 178 -
        Ketentuan lebih lanjut mengenai tanggung jawab terhadap barang yang diangkut diatur dengan peraturan Menteri.

  CHAPTER VII -

    ART 179 -

      POINT c.
        sarana perkeretaapian; dan

      POINT d.
        kerugian yang diderita oleh pihak ketiga.

      PARA (1)
        Asuransi tanggung jawab terhadap pengguna jasa sebagaimana dimaksud dalam Pasal 179 huruf a meliputi:

        POINT a.
          asuransi penumpang yang mengalami kerugian, lukaluka, atau meninggal dunia yang disebabkan oleh pengoperasian angkutan kereta api sebagaimana dimaksud dalam Pasal 168 ayat (1); dan

        POINT b.
          asuransi barang terhadap kerugian sebagaimana dimaksud dalam Pasal 174 ayat (2).

      PARA (2)
        Ketentuan lebih lanjut mengenai asuransi tanggung jawab sebagaimana dimaksud pada ayat (1) diatur dengan peraturan Menteri.

    ART 181 -
      PARA (1)
        Asuransi awak sarana perkeretaapian dan orang yang dipekerjakan oleh penyelenggara sarana perkeretaapian di atas kereta api sebagaimana dimaksud dalam Pasal 179 huruf b meliputi asuransi kesehatan dan asuransi kecelakaan kerja.

      PARA (2)
        Besarnya nilai pertanggungan asuransi sebagaimana dimaksud pada ayat (1) sesuai dengan ketentuan peraturan perundang-undangan.

    ART 182 -
      PARA (1)
        Asuransi sarana perkeretaapian sebagaimana dimaksud dalam Pasal 179 huruf c meliputi risiko kerusakan sarana perkeretaapian.

      PARA (2)
        Besarnya nilai pertanggungan asuransi sebagaimana dimaksud pada ayat (1) sesuai dengan nilai pertanggungan paling sedikit senilai sarana perkeretaapian.

    ART 183 -
      PARA (1)
        Asuransi kerugian yang diderita oleh pihak ketiga sebagaimana dimaksud dalam Pasal 179 huruf d meliputi luka-luka, cacat, meninggal dunia, dan kerugian harta benda.

      PARA (2)
        Besarnya nilai pertanggungan asuransi sebagaimana dimaksud pada ayat (1) sesuai dengan ketentuan peraturan perundang-undangan di bidang asuransi.

  CHAPTER VIII -

    ART 184 -
      Ketentuan mengenai lalu lintas dan angkutan kereta api untuk kereta api kecepatan tinggi, monorel, motor induksi linier, gerak udara, levitasi magnetis, trem, dan kereta gantung, sesuai dengan karakteristiknya diatur dengan peraturan Menteri.

  CHAPTER IX -

    ART 185 -
      Peralihan masinis menjadi pemimpin perjalanan kereta api dilaksanakan paling lama 2 (dua) tahun sejak berlakunya Peraturan Pemerintah ini.

  CHAPTER X -

    ART 186 -
      Pada saat Peraturan Pemerintah ini mulai berlaku, Peraturan Pemerintah Nomor 81 Tahun 1998 tentang Lalu Lintas dan Angkutan Kereta Api (Lembaran Negara Republik Indonesia Tahun 1998 Nomor 133, Tambahan Lembaran Negara Republik Indonesia Nomor 3777) dicabut dan dinyatakan tidak berlaku.

    ART 187 -
      Pada saat Peraturan Pemerintah ini mulai berlaku, semua peraturan pelaksanaan yang mengatur mengenai lalu lintas dan angkutan kereta api yang ada dinyatakan masih tetap berlaku sepanjang tidak bertentangan dan/atau diganti dengan peraturan yang baru berdasarkan Peraturan Pemerintah ini.

    ART 188 -
      Peraturan Pemerintah ini mulai berlaku pada tanggal diundangkan.
